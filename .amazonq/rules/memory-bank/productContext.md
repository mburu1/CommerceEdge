# Product Context — CommerceEdge

## Why It Exists
Traditional portfolio projects demonstrate basic CRUD. CommerceEdge instead explores the full complexity of enterprise retail: store management, POS, offline operation, payments, hardware peripherals, e-commerce, messaging, caching, observability, and distributed infrastructure.

## Problems It Addresses
Modern retail systems must handle: store/channel management, product catalogs, pricing, promotions, customers, inventory, carts, orders, payments, returns, POS operations, hardware peripherals, offline operation, e-commerce, auth, distributed integrations, caching, messaging, observability, auditability, resilience, and high transaction volumes.

## Target Users (Learning Context)
A developer building transferable skills in C#/.NET, TypeScript, React, POS architecture, Commerce Runtime concepts, and enterprise engineering practices — specifically aligned with Dynamics 365 Commerce development patterns.

## Key Experiences
1. POS — TypeScript client with operations, triggers, requests, handlers, views, services
2. Commerce API — ASP.NET Core REST API
3. E-Commerce — React + TypeScript web storefront
