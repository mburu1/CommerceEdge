# Project Brief — CommerceEdge

## What It Is
CommerceEdge is a production-oriented omnichannel retail commerce and POS platform, built as a hands-on learning and portfolio project. It is architecturally inspired by Microsoft Dynamics 365 Commerce but is an independent implementation.

## Core Purpose
Demonstrate enterprise retail commerce architecture across POS, Commerce Runtime, Commerce APIs, Scale Unit, hardware integrations, e-commerce, payments, inventory, customers, orders, security, observability, and distributed infrastructure.

## Primary Stacks
- Backend: C#/.NET (ASP.NET Core, EF Core, Dapper, SQL Server, Redis)
- POS Client: TypeScript
- Web Commerce: React + TypeScript (Vite, TanStack Query, React Router)

## Status
🚧 Active development — architecture and documentation phase precedes implementation. Currently in Phase 1 (Architecture).
