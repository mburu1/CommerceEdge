# CommerceEdge Web

React + TypeScript e-commerce storefront built with Vite, TanStack Query, and React Router.

## Structure
- `src/app/` — App shell and providers
- `src/components/` — Shared UI components
- `src/features/` — Feature modules (catalog, cart, checkout, customers, orders)
- `src/pages/` — Route-level page components
- `src/hooks/` — Custom React hooks
- `src/services/` — API client services
- `src/models/` — TypeScript types and interfaces
- `src/routes/` — Route definitions
- `src/lib/` — Utilities and helpers

## Getting Started
```bash
npm install
npm run dev
```
